# Player simulator | report

Generated by `npm run sim` (12 matches per cell, all seeded). Simulated people swing synthetic phone swings built from the teach and tuning recordings and read by the real detector; their timing skill is an assumption (src/sim/players.ts), not a measurement. Match length is first to 3 games unless a table says otherwise.

## 1. The synthetic swings

486 synthetic swings from 81 recorded ones: 98% detected, 100% with the right direction, median peak 890 deg/s, median power 0.46. The comparison with the held-out recordings is in tests/sim/swings.test.ts.
